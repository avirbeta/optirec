# OptiRec 1.1.0

Запись экрана **Minecraft 1.16.5** (Fabric) в MP4 через **FFmpeg**. Захватывает **весь экран — включая GUI, чат и меню** — через миксин на `GameRenderer.render` (RETURN), без лагов даже на слабом железе.

## Что нового в 1.1.0

- Исправлена гонка при старте: `recording` выставлялся после запуска writer-потока, из-за чего поток мог сразу завершиться и кадры не писались.
- Буферы кадров переиспользуются: меньше аллокаций и нагрузки на GC (раньше каждый кадр создавался массив на несколько МБ).
- Путь к FFmpeg кэшируется, лишние процессы `ffmpeg -version` больше не запускаются.
- Остановка FFmpeg стала аккуратной: сначала ждём завершения, потом принудительно убиваем.
- При смене разрешения окна кадры больше не читаются впустую через `glReadPixels`.
- Понятные сообщения об ошибках вместо всегда «FFmpeg не найден».
- Исправлен текст в меню: запись идёт в 24 FPS, а не 30.
- Добавлены CI-сборка и MIT-лицензия.

## Особенности

- Захват полного кадра с GUI/чатом/меню (не только 3D-мир).
- Оптимизировано для слабых ПК: 24 FPS капа, `-preset ultrafast`, `-crf 26`, `-threads 0`, пропуск дорогого `glReadPixels`, когда кадр не нужен.
- Вертикальный флип кадра (bgr0 → mp4).
- HUD-индикатор ● REC.
- Меню настроек с проверкой FFmpeg.

## Управление

- **F8** — старт/стоп записи
- **F9** — меню настроек

Требуется установленный **FFmpeg** в системе (путь можно задать переменной `FFMPEG_PATH`).

## Сборка

Требуется: JDK 17, Gradle 7.6+, Fabric Loom 0.12.56, yarn `1.16.5+build.10:v2`, fabric-api `0.42.0+1.16`.

```bash
gradle build --no-daemon
```

Готовый мод: `build/libs/optirec-1.1.0.jar`.

Сборка также запускается в GitHub Actions при каждом push — готовый jar лежит в артефактах workflow.

## Установка

1. Установи Fabric Loader и **Fabric API** `0.42.0+1.16` для 1.16.5.
2. Положи `optirec-1.1.0.jar` в папку `mods/`.
3. Убедись, что FFmpeg установлен.
4. Запусти игру, нажми **F8** для записи.
